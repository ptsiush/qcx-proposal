# 08 — Return to Qubic Incubation

## Primary mechanism: capped fee share

| Parameter | Proposal |
|---|---|
| Base | QCX platform fee revenue (the 15% platform share in `07`), net of refunds |
| Share | 15% of the base |
| Start trigger | First month after M4 (public launch) |
| Cap | 1.5× the total amount funded by Qubic Incubation |
| Duration | Until the cap is reached, or 5 years, whichever comes first |
| Reporting | Monthly report in this repository plus on-chain receipts of payments |
| Exclusions | Trial credits given to clients for free |

## Why this mechanism

The return comes from the same source of value as the product: clients paying for compute. No token is issued. QCX has no reason to have its own token, because it settles in USDT and QUBIC.

## Indirect return to the Qubic ecosystem

Beyond the fee share, QCX creates continuous QUBIC buy pressure and burns funded by external clients (about $850 of buybacks per $1,000 of client spend in the planning model, see `07`). This is reported publicly every month.
