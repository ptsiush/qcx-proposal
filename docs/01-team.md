## Pool partner — to be approached after approval

QCX distributes jobs to miners through an existing Qubic mining pool (candidates: qubic.li, JetSki, Apool, MinerLab), the same way pools already handle DOGE mining payouts.

Pool negotiations will start once the Incubation Board approves the concept, so that the pool is approached with a backed proposal. If no pool agrees in time, M1 falls back to a standalone opt-in worker that miners run directly (see `09` and `10`).

The Incubation Board's help with an introduction to a pool operator would speed this up.
