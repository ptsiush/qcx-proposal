# QCX — Qubic Compute Exchange

**Sell Qubic miners' CPU power to real-world clients. Revenue buys back QUBIC.**

QCX is a marketplace where external clients rent CPU compute from the Qubic mining network for sandboxed batch jobs. Clients pay in USDT. That revenue is used to buy QUBIC on the market, which is paid out to the participating miners through existing Qubic pools. Any surplus is burned.

This is the same economic loop Qubic already runs with DOGE mining (external revenue → QUBIC buyback → miners / burn). The difference is the source of revenue: QCX sells compute to paying customers instead of mining another chain.
